# Dirette YouTube

Progetto Dokploy **Dirette YouTube**, servizio **Ciamioncino · Ring Road**.
Il mini PC esegue in locale Godot Linux e OBS. I file di progetto e le
registrazioni sono in `/home/davide/projects/youtube-live` sul mini PC.

Il servizio usa l'immagine locale `youtube-live:local`. La definizione Raw in
Dokploy corrisponde a [compose.yaml](compose.yaml). Il Dockerfile e il runbook
sono nel checkout di Ciamioncino, sotto `deploy/youtube-live`.
