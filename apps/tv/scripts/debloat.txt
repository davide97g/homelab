# Packages scripts/debloat.sh disables on the Philips 65PUS8505 (Android 12, TPM191E).
#
# One package per line; `#` starts a comment. Lines not installed on the set are
# skipped, so this list can name more than the TV actually ships. Everything is
# `pm disable-user --user 0`: no root, nothing uninstalled, `debloat.sh --restore`
# puts back exactly what it took away.
#
# "Medio": the Google feed and its ads, Google's own media apps, store-demo and
# tutorial leftovers, telemetry senders. Kept on purpose, never list these:
#   com.android.vending                 Play Store (updates, installs)
#   com.google.android.gms / gsf        Play services (everything breaks)
#   com.google.android.apps.mediashell  Chromecast built-in
#   com.google.android.katniss          Assistant / voice search
#   com.google.android.tvlauncher       stock launcher: --launcher in deploy-tv.sh owns it
#   com.google.android.tv.remote.service  Google TV remote on the phone
#   org.droidtv.*  that are not named below — JointSpace, Ambilight, EasyLink, inputs
#                    and the TV tuner live under that prefix. Never wildcard it.
