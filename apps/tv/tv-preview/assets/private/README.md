# assets/private — never committed

Artwork that is fine on our own TV but not ours to publish in a public repo.
Everything here except this file is git-ignored.

- `meadow.jpg` — studio background. Hero painting from duna.com's landing page,
  text removed by inpainting (OpenCV Telea) and upscaled to 1920×1080.
  If this folder is empty after a fresh clone, the panel falls back to a flat
  `#FBF7F2`: drop any 1920×1080 picture here under that name.

- `desktop-hp.html` — the pixel-art desktop wallpaper with the menu bar and dock mocked over it; source for the launcher's `scene.html` (see `jarvis-tv/app/src/private/README.md`).
